⚠️ Action Required: Database Setup

Your game cannot save or load because your Firestore Database is locked.

1. Go to Firebase Console:

Click here to open your Database Rules

2. Paste these Exact Rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Note: This sets your database to public mode for testing.

3. Click "Publish"
